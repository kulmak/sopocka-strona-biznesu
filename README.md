# Sopocka Strona Biznesu

**Miasto i firmy oddychają tym samym rytmem.**

A merchant panel for small businesses in Sopot, delivered as a new tab in the municipal resident card
(Karta Sopocka). Built for the Visa Data Sprint, category *Public Challenge*.

> **Status:** under construction. The 60-second front door, the run instructions and the claim→command
> table land in `docs/` — see `AGENTS.md` for the build order.

- `PLAN.md` — the master plan (what we build, in what order, and why)
- `SWARM.md` — the work orders
- `AGENTS.md` — the rules of this repository
- `contracts/AGGREGATE.md` — the data contract
- `../research/` — twelve audit reports on everything that came before
